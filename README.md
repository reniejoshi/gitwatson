### Local Development

```bash
# 1. Rust backend (http://127.0.0.1:3000/api/users/{username})
cd backend && cargo run

# 2. React frontend (http://localhost:5173/gitwatson/)
cd frontend && npm install && npm run dev
```

### Keyboard Controls

| Key | Action |
| :--- | :--- |
| <kbd>/</kbd> | Focus the `://github.com` search bar |
| <kbd>Enter</kbd> | Run profile lookup |
| <kbd>Esc</kbd> | Clear search query |
